각 split은 정답 객체 기준으로 세 클래스가 균등하게 구성되어 있다.

-   클래스별 전체 객체 비율: 각각 33.3%.

### FP·FN 해석과 확인 방법

현재 예측 CSV에는 객체 예측이 한 건도 없고, Validation 정답 라벨에는
객체가 30개 있다. 따라서 해당 Validation 평가에서 예측과 정답을 비교하면
**FN은 30개, FP는 0개**로 해석된다. 이는 예측 행이 0개이고 정답 객체가
30개라는 사실에 따른 결과다.

단, 별도의 수동 IoU 매칭표를 만들어 FP/FN을 독립적으로 집계한 것은
아니다. 정식 지표는 Ultralytics `model.val()`의 평가 출력이며, 위
FP/FN은 빈 예측과 정답 라벨 수에 근거한 해석이다.

## 9. 한계 및 주의사항

1.  **합성 데이터 한계:** OpenCV로 생성한 단순 도형 데이터이므로 자연
    사진·복잡한 배경·실제 환경에서의 성능을 대표하지 않는다.
2.  **학습 이력 불확실성:** 체크포인트의 `data` 경로가 다른 PC를
    가리킨다. 실제 학습 데이터와 학습 과정을 현재 자료만으로 완전히
    검증할 수 없다.
3.  **짧은 학습 설정:** 체크포인트에는 `epochs=2`가 기록되어 있다. 이
    설정이 실제 학습에 적용되었는지, 최종 모델이 어떤 시점의
    가중치인지는 추가 증거가 필요하다.
4.  **가상 기록 배제:** `data/metrics_example.csv`는 예시용 가상 학습
    기록이다. 실제 YOLO 성능·학습 이력으로 사용하지 않았다.
5.  **Fixture 배제:** `data/boxes_fixture.csv`의 점수와 박스는 원리
    연습용으로 손으로 정한 값이다. YOLO 예측으로 사용하지 않았다.
6.  **Test 미사용:** 이번 실험의 평가 split은 Validation이다. Test는
    모델 평가·임계값 선택에 사용하지 않았다.
7.  **추적 성능 미평가:** 예측 Track ID가 생성되지 않아 ID switch 및
    추적 품질을 평가할 수 없다.
8.  **실시간 속도 미측정:** AVI의 FPS는 동영상 파일 메타데이터다. 처리량
    기준의 추론 FPS나 지연 시간 측정값이 아니다.
9.  **라이선스:** Ultralytics 및 사용 모델 가중치의 라이선스·배포 조건을
    별도로 확인하지 않았다. 외부 배포 전 해당 버전과 가중치 출처의
    라이선스를 확인해야 한다.
10. **환경 범위:** CPU 실행 결과이며 GPU/CUDA 성능을 검증한 실험이
    아니다. OpenCV 버전은 앞서 제공된 환경 출력에 근거하며 이번 검증
    로그에서 재확인하지 않았다.

## 10. 최종 결론

이번 실습에서는 YOLO26n 기반 이미지 탐지와 동영상 추적 파이프라인을
실행하고, 결과 CSV·요약 JSON·출력 동영상을 생성했다. 동일 모델로
재실행한 결과와 이미지 처리 개수는 일치하여 재현성 비교는 통과했다.

그러나 Validation 12장, 정답 객체 30개에 대해 탐지 결과가 0건이었고
Precision, Recall, mAP50, mAP50-95가 모두 0이었다. 동영상 30프레임에서도
추적 결과가 생성되지 않았다. 따라서 이번 실험은 **실행 및 재현성 검사는
완료했으나, 객체 탐지·추적 성능은 확보하지 못한 실험**으로 결론 내린다.

향후에는 현재 `demo.pt`의 원본 학습 기록과 데이터 경로를 확인하고, 학습
데이터·라벨·학습 epoch·최종 가중치 선택 과정을 검증한 뒤 새 모델을
대상으로 별도의 실험을 수행해야 한다. 이번 보고서의 수치는 현재 실제
실행 결과만을 기록했으며, fixture나 가상 학습 기록을 실제 결과로
대체하지 않았다.
